# Teams AWS/FinOps Webhook Reporter

This script sends AWS cost data to Microsoft Teams through a Workflow Webhook:

AWS Cost Explorer / FinOps
        ↓
        Python script
        ↓
Adaptive Card JSON
        ↓
Teams Workflow Webhook
        ↓
Teams Channel

## 1. Installation

Windows:

```powershell
py -m pip install -r requirements.txt
```

Linux:

```bash
python3 -m pip install -r requirements.txt
```

## 2. Configure the Teams Webhook

The Teams Workflow should be configured with:

"Generate a webhook URL that lets anyone send external systems updates into a channel using rich adaptive cards"

Copy the Webhook URL generated by the Workflow.

Store it in an environment variable instead of writing it directly in the script.

Windows PowerShell:

```powershell
$env:TEAMS_WEBHOOK_URL="https://your-webhook-url"
```

Windows CMD：

```cmd
set TEAMS_WEBHOOK_URL=https://your-webhook-url
```

Linux：

```bash
export TEAMS_WEBHOOK_URL="https://your-webhook-url"
```

## 3. Test Teams Without Accessing AWS

```bash
python teams_report.py --no-aws
```

If the request succeeds, the Teams channel should receive an Adaptive Card.

You can also generate the JSON payload without sending it:

```bash
python teams_report.py --no-aws --dry-run
```

## 4. Query AWS Cost Explorer

The script uses these defaults:

- Region: us-east-1
- Current month
- Current week, from Monday through today
- Yesterday
- Metric: `UnblendedCost`
- Currency: `USD`

Run:

```bash
python teams_report.py
```

AWS credentials use the default boto3 credential chain.

For example, if the AWS CLI is already configured:

```bash
aws configure
```

the script can be run directly.

You can also specify a region explicitly:

```bash
python teams_report.py --region us-east-1
```

## 5. Add a Public Image

If your image is already available at an HTTPS URL:

```bash
python teams_report.py \
  --image-url "https://example.com/aws-cost.png"
```

Windows PowerShell:

```powershell
python teams_report.py --image-url "https://example.com/aws-cost.png"
```

This is the recommended approach.

## 6. Use a Local Image

For example:

```text
C:\monitor\cost.png
```

Run:

```powershell
python teams_report.py --image-file "C:\monitor\cost.png"
```

The script automatically converts the image to a Base64 Data URI and embeds it in the Adaptive Card.

Note: Teams Workflow/Webhook messages have size limits. For large images, avoid Base64 and host the image at an HTTPS URL, then use `--image-url`.

## 7. Test With Custom Values Without Accessing AWS

For example:

```powershell
python teams_report.py `
  --no-aws `
  --month 1234.56 `
  --week 234.56 `
  --yesterday 45.67
```

## 8. Future FinOps Extensions

AWS querying is isolated in:

```python
collect_aws_costs()
```

Additional cost categories can be added, for example:

```text
EKS
EC2
RDS
S3
Lambda
CloudFront
Account A
Account B
```

For example, the report could eventually include:

AWS Cost Report

This Month      $1,284.32
This Week         $312.45
Yesterday          $48.21

EKS               $423.18
EC2               $312.54
S3                 $87.32
RDS                $156.42

Cost Explorer `GroupBy` and `Filter` support can also be added.

## 9. Schedule Execution

On Windows, use Task Scheduler.

On Linux, use cron. For example, to run every day at 09:00:

```cron
0 9 * * * /usr/bin/python3 /opt/teams/teams_report.py
```

To run a test every minute:

```cron
* * * * * /usr/bin/python3 /opt/teams/teams_report.py --no-aws
```

## 10. Security Notes

The Webhook URL is itself a credential. Do not commit it to Git.

Use:

```text
TEAMS_WEBHOOK_URL
```

Store it in an environment variable, a secret manager, or another secure configuration store.

If the Webhook URL is exposed, regenerate or update it in the Teams Workflow.
